# Paradan Aqua

E-commerce starter for Paradan Aqua with direct UPI payment workflow and 5-level Unilevel affiliate program.

## Included
- Next.js storefront
- Admin dashboard structure
- Affiliate dashboard structure
- UPI checkout / UTR verification UI
- Supabase/Dogrow integration configuration
- Commission model: 10% / 5% / 3% / 2% / 1%

## Run
Copy `.env.example` to `.env.local`, add Supabase credentials, then run `npm install` and `npm run dev`.
